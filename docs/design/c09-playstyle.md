## 9. 流派设计

> **职业是 Build，不是角色。** 下面四条是"星图往哪个方向点"，不是"创建角色时选谁"。

### 9.1 轴与位置

| 轴 | 两端 |
|:--|:--|
| 空间 | 前排 ↔ 后排 |
| 时间 | 爆发 ↔ 持续 |
| 功能 | 控制 ↔ 输出 |
| 范围 | 单点 ↔ 群体 |

| 流派 | 空间 | 时间 | 功能 | 范围 |
|:--|:--|:--|:--|:--|
| 重甲 | 前排 | 持续 | 控制 | 群体 |
| 法术 | 后排 | 爆发 | 控制 | 群体 |
| 游侠 | 后排 | 持续 | 输出 | 单点 |
| 刺客 | 前排切入 | 爆发 | 输出 | 单点 |

### 9.2 空窗期 = 四种"花时间的方式"

> **法术把时间花在未来，重甲花在现在，游侠花在距离，刺客花在消失。**

| 流派 | 空窗期在做什么 | 承载它的消耗品 |
|:--|:--|:--|
| 法术 | 预铺地面效果、走位回蓝、找蓝药 | **法力** |
| 重甲 | 继续普攻（攒节奏）、卡位、招架 | **耐久** |
| 游侠 | 保持距离、装填、布置陷阱 | **箭矢** |
| 刺客 | 脱离、潜行、重新找进场窗口 | **技能 CD** |

### 9.3 技能骨架（初稿，待细化）

**法术**

| 技能 | 作用 |
|:--|:--|
| 预铺地面（火墙 / 毒池 / 冰面） | 提前 3–5 秒布置，敌人走进来才触发 |
| 控制（冰环 / 减速区域） | 接反应链 |
| 高耗爆发（引导） | 有明显读条，可被打断 |
| 短距闪现 | 唯一保命，耗蓝 |

**重甲**

| 技能 | 作用 |
|:--|:--|
| 冲锋 | 位移 + 撞击伤害 |
| 招架 | 见 8.6 |
| 拉拽 / 推击 | 地形杀的执行者 |
| 横扫 | 清填线 |
| 威慑 / 嘲讽 | 拉怪、逼目标转向 |

**游侠**

| 技能 | 作用 |
|:--|:--|
| 标记 | 搜打撤的信息核心 |
| 陷阱 / 绊索 | 区域封锁、断后 |
| 后跳射击 | 位移时仍在输出 |
| 穿透箭 | 对群，代价是穿甲低 |
| 鹰眼 | 短暂看穿墙体 / 雾 |

**刺客**

| 技能 | 作用 |
|:--|:--|
| 突进 / 背刺 | **背后命中伤害翻倍**（2.5D 有朝向，天然成立） |
| 潜行 | 最强信息战技能 |
| 烟雾 / 致盲 | 脱离 + 创造背身 |
| 毒刃 | DOT，配合"火 + 毒引爆" |
| 斩弱 | 对低血量目标额外伤害（**不是处决**） |

> **批次一实稿（2026-11-23/24）**：焚天 / 势 / 剑势如虹 / 剑贯长虹 / 封疆 / 斥 的机制、初值与
> 归属见 [`skills-batch-1.md`](skills-batch-1.md)。核心是**「一个 build 一个终极」**：
> - **数量**：`kind='ult'` 的星图节点**全局最多点亮 1 个**（`canPick` 直接拒，不是"点了装不上"）。
>   技能栏仍是 7 格、不做专属终极格 —— 既然点不了第二个，专属格子只是装饰。
> - **方向**：亲和要求决定"为了这个终极得先吃什么属性"。势挂在**火**（爆发）上，
>   剑势如虹要火 ≥5、剑贯长虹要风 ≥5 —— 想开前者就得吃「炭壳 +6% 生命」，
>   想开后者就得吃「疾行 +近战距离」。**不需要加金 / 土新色**，6 色语义不变。
> - 「势」不是流派专属：任何流派、任何武器，点出节点就能攒；只点势不点终极是有意亏本。
>   它不推翻 8.3，只把 8.3 收窄为「没有**与生俱来**的流派资源，流派资源必须可点选、可放弃」
>   —— 该措辞待确认后再改 8.3 正文。
