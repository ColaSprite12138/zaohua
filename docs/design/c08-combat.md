## 8. 战斗系统

### 8.1 基本规则

| 规则 | 决定 |
|:--|:--|
| 暴击 | **不做** |
| 破防 / 处决 | **不做** |
| 部位判定 | **不做**（只做命中判定，2.5D 不做 FPS 的精细命中） |
| **输出来源** | **两条轴并立**：**技能轴**（耗蓝 + CD）与 **普攻轴**（不耗蓝，耗耐久） |
| **谁更强** | **由 build 决定，系统不钦定**。技能流靠解锁技能 + 法力续航；普攻流靠攻速 / 距离乘区 + 「势」这类命中循环 |
| 基础攻速 | **仍然偏低** —— 但攻速是**成长项**，见 8.1.1 |
| 胜负来源 | 技能释放、连招、躲避、招架、地形、套装特效 + **普攻节奏（攻速窗口、走砍）** |
| 普攻后摇 | **可被技能 / 闪避取消**（取消本身就是技巧点） |

> **2026-11-24 修订（用户指出）**：原表写「主要输出来源 = 技能，普攻为资源 / 收尾 / 过渡」——
> 那是只有 8 个法术技能时的结论。现在「剑势如虹」这类 build 就是用攻速 / 距离把普攻打成主输出。
> 表格必须认这件事，否则实现时不自觉会把普攻往弱里调（而它的弱应该由**耐久 + 站位**体现，
> 不是由数值硬压）。

#### 8.1.1 攻速：基础低，成长只在技能与星图

| 项 | 规则 |
|:--|:--|
| 基础攻速 | **偏低，不变**。让"手感慢"成为默认值，攻速才成为有感知的成长 |
| 来源 1 · 技能 | 「剑势如虹」+40%（消耗「势」换爆发窗口） |
| 来源 2 · 星图 | 新增乘区 `atk_speed_pct`（节点 / 大点） |
| **来源 3 · 装备** | **不给攻速**。词条里没有这一项，别加 |
| 为什么装备不给 | 攻速是**手感参数**。进了词条，装备差距会直接变成"手速差距"，与 7.5「不能出现必败局」冲突；装备的纵向强度已经由白值与耐久承担 |
| **管什么** | **只管普攻间隔与普攻后摇**。**不改技能读条、不改 CD** —— 否则技能流也会去点攻速，双轴又混成一条 |
| 上限 | **按 TTK 锚点反推**（12.3：PVP 10–20 秒），不是拍一个百分比；叠满要能做除法验算 |
| 实现 | `combat/modifiers.ts` 的 effect 从 4 种扩到 5 种；**攻速必须进 `S` 与 hash** —— 它改变攻击间隔→改变命中时序，不进就是帧同步分叉 |

> **普攻流的对价不是蓝，是耐久与站位**：近战普攻不耗蓝但耗耐久（7.4），且必须贴脸。
> 技能流用蓝和 CD 买距离，普攻流用耐久和风险买持续 —— **两边都要有账，不能一边免费。**

**平衡锚点（做数值时的判据）**：普攻流的**平均 DPS 应更高**、**峰值 DPS 应更低**。
它用"没有空窗"换"没有爆发"；如果两边的均值与峰值都接近，双轴就退化成同一条轴，
只剩操作方式不同 —— 那时该调的不是数值，是设计。

### 8.2 技能栏

| 项 | 规则 |
|:--|:--|
| 主动技能栏 | **7 格** |
| 位移技能 | **算主动技能，占 1 格** |
| 空格闪避 | **角色自带，独立于技能栏**（不占格） |
| 实际能带几个 | 点数预算天然把主动技能压到 **4–5 个**（因为被动也吃点数），7 格是宽松上限 |
| 技能解锁成本 | **便宜**（推荐 1 点）—— 否则玩家不敢解锁"用不上"的技能，技能库永远只有 4 个，丰富感消失 |

> **取舍发生在星图，不发生在战前**：解锁什么就带什么，没有"进图前选 4 个"的环节。
> 好处：规则简单；代价：点错技能只能洗点（免费，所以代价很低）。

**普攻流的格子更空**：点数花在攻速 / 距离乘区上，主动技能往往只带 **3 个**
（1 终极 + 1 位移 + 1 应对），表里的"4–5 个"是均值、不是下限。
这不是缺陷 —— 普攻流本来就是"少按钮、多节奏"，和 8.1「两条轴」是一回事。

### 8.3 资源与消耗品

| 资源 | 规则 |
|:--|:--|
| 生命 | 常规 |
| 法力 | **不自动恢复**。技能释放消耗（所有流派都耗，依赖度不同）。恢复靠**蓝药**（缓慢回复） |
| 弹药 / 耐久 | 见 7.4 |

> **没有"流派专属资源"**（曾经设计过战士怒气，已废弃）。
> 原因：星图是所有人共用的，专属资源放前面则人人都有，放后面则前期没有，都不成立。

### 8.4 状态效果表

**硬控**（禁止操作类）

| 状态 | 效果 | 反制 |
|:--|:--|:--|
| 晕眩 | 禁止操作 | 无解，但时长短（≤1.5s） |
| 石化 | 禁止操作 | 连点闪避缩短时长；被击碎时受额外伤害 |
| 睡眠 | 禁止操作 | 受击即醒；睡眠中首次受伤 +50% |
| 禁锢 | 禁止移动 / 位移技能 / 闪避 | **可以原地攻击、放非位移技能**（不额外给反制） |

**软控 / 削弱**

| 状态 | 效果 |
|:--|:--|
| 减速 | 移动速度降低（追逃的基础） |
| 迟滞 | 攻速 / 施法速度降低 |
| 沉默 | 禁止释放技能 |
| **缴械** | 禁止普通攻击（对法系/刺客影响天然较小，符合设计意图） |
| 目盲 | 大幅降低视野 |
| 标记 | 位置在对方小地图显示一段时间 |
| 足迹 | 留下可追踪痕迹 |
| 重伤 | 治疗效果降低（比"点燃=完全禁疗"温和的一档） |
| 破甲 | 护甲降低 |
| 易伤 | 受到伤害增加 |
| 燃蓝 | 按损失法力造成伤害 |
| CD 延长 | 技能冷却变长 |

**持续伤害**

| 状态 | 效果 |
|:--|:--|
| 流血 | 持续伤害 |
| 中毒 | 可叠层，持续伤害 |
| 点燃 | 持续伤害，**效果结束前治疗无效** |

**位移类**

| 状态 | 效果 |
|:--|:--|
| 击退 / 击飞 | 位移；撞墙 = 额外伤害 + 短暂眩晕 |
| 拉拽 | 把目标拉向自己 |
| 打断 | 打断引导类技能 |

**规则**：

- **不做状态累积条**，命中即上状态（PvP 里展示进度条太乱）
- **不做状态递减（DR）** —— 玩家已决定，理由：硬控本身是"难命中 + 长 CD + 非指向性"，且递减有理解成本。**风险见第 14 章 R1**
- **硬控均为非指向性技能，CD 较长**；越难命中，命中奖励越大
- **引导类技能必须有极显眼的引导动作**（读条提示），让对手能反应、能打断

### 8.5 反应链

只做 3 类、固定条目，**不做"状态两两组合"**（避免 N² 学习成本）。

**元素：水 / 火 / 毒 / 雷 / 冰 / 风（共 6 种）**

| 组合 | 效果 |
|:--|:--|
| 水 + 冰 | 冻结（硬控） |
| 水 + 雷 | 麻痹，向附近敌人**传导** |
| 火 + 毒 | **引爆**毒层，瞬间伤害 |
| 风 + 火 | 火势蔓延（火焰区域扩大） |
| 风 + 毒 | 毒雾扩散（中毒区域扩大） |

> 6 种元素、5 条反应，学习成本可接受。**只认这张表**，不做"任意两两组合"。
> （v5 删掉了"油"：地面可燃物属于**场景属性**，不是玩家可施加的元素。）

**物理反应**

| 组合 | 效果 |
|:--|:--|
| 击退 / 拉拽 + 墙 | 撞墙：伤害 + 短暂眩晕 |
| 击退 + 陷阱 / 毒池 / 边缘 | 地形杀 |
| 流血 + 位移 | 地面血痕，可被追踪 |
| 石化 + 击碎 | 碎裂：高额伤害，终结石化 |

**技能链**

| 组合 | 效果 |
|:--|:--|
| 控制命中 → 高伤害技能 | 必中 / 极高命中 |
| 位移技能 → 已铺好的地面效果 | 把目标送进火海 / 毒池 |

> **连招原则：每一环都必须单独有收益。** 不允许"B 技能只为 A 技能服务"——B 空了 A 也空了时，B 本身要有位置/资源/减速等价值，否则玩家不敢用。

### 8.6 招架（Parry）

**不做帧级弹反，做"招架式"**（Fiora W 类），因为俯视角 + 多目标 + 输入延迟不适合帧级判定。

| 项 | 规则 |
|:--|:--|
| 架势 | 按下进入 **0.4–0.6 秒**招架架势 |
| 生效 | 姿态内受到**正面**攻击 → 完全免伤 + 反击 |
| 方向 | **只挡正面**，侧面与背后照常受伤 |
| 失败 | **不可取消的僵直**（惩罚足够重，配得上收益） |
| 表现 | **强 hitstop + 白闪 + 金属音效**（手感 80% 来自这三样） |

### 8.7 地形（2.5D 独有优势）

| 用法 | 说明 |
|:--|:--|
| 高度差 | 高台可打下面，下面打不到上面 |
| 可推落边缘 | 击退 → 摔伤 + 脱离 |
| 撞墙 | wall bounce（伤害 + 短暂眩晕） |
| 可破坏墙 | 打穿创造新路线（与可破坏物共用系统） |

### 8.8 视觉语言（体素画风下状态必须"看得见"）

| 状态 | 表现 |
|:--|:--|
| 流血 | 地面血渍 + 红色粒子 |
| 中毒 | 绿色气泡 |
| 点燃 | 橙色火焰 + 黑烟 |
| 石化 | 灰化 + 动画停止 |
| 睡眠 | 头顶 Z |
| 眩晕 | 头顶转圈星 |
| 减速 | 脚下蓝色拖尾 |
| 招架成功 | 白闪 + hitstop + 金属火花 |
| **自己身上的状态** | **技能栏正上方一行正方形图标**（2026-11-18）：一个汉字 + 顺时针「时针阴影」+ 层数角标。阴影画的是**已经过去的比例**（扫满 = 到点），不是剩余 —— 反着写会让玩家以为还剩一大截。悬停时该格**不出阴影**（看清字形），图标上方出面板：名字（含层数）/ `剩 x.x 秒` / `分类 · 一句话` |

> 与 `docs/art-style.md` 一起维护；debuff 在画面上"看不见"就等于不存在。
>
> **怪物头顶 + 玩家脚下 + 玩家 HUD** 是同一套状态的三层读法：怪身上的用粒子/光环（8.8 上一张表），
> 自己的用**精确到 0.1 秒的图标行**。前者回答「它在受什么影响」，后者回答「我还有多久不能动」。
