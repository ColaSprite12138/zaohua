## 维护规矩

1. **改规则 → 改对应 `cNN`**，同时在 `c13` 决策总表记一行（定过什么，比改在哪更重要）。
2. **代码落地一批 → 只改 `c15 §15.0` 的表行**；批次的过程说明不往设计文档里堆。
3. **新模块的设计先写 `docs/design/<module>.md` 草稿**，定稿后才回写到对应 `cNN` + 一行指针。
4. **不搬正文、不动章节号。** 章节号是外部锚点（`HANDOFF` / `CONTEXT` / `EXPERIENCE` 都在引用）。
5. 被推翻的结论标 ~~删除线~~ 并注明原因，不静默删除。
