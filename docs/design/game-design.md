## 0. 一页速览

**是什么**：2.5D 俯视角、体素画风的搜打撤（Extraction Looter）游戏，战斗手感对标暗黑破坏神 / Grim Dawn，风险规则对标逃离塔科夫 / 逃离鸭科夫。

**三个卖点**：

1. **给"鼠鼠玩家"一条活路** —— 纯 PVE 副本可以安全刷装备，不必被强制 PVP。代价是产出有硬上限。
2. **装备是消耗品，不是奖杯** —— 刻意不把顶级装备做成终极追求（Dungeonborne 的教训）。
3. **靠机制分胜负，不靠数值碾压** —— 无暴击、无部位判定，胜负来自技能释放、连招、躲避、招架、地形。

**一句话循环**：

> 带装备下场 → 打怪 / 抢事件 / 破坏物 → 攒货 → 从传送门撤离 → 局外换成更高的下一局筹码。

## 1. 定位与差异

| 项 | 我们的选择 | 参照物 |
|:--|:--|:--|
| 视角 | 2.5D 俯视角 | 暗黑 / Grim Dawn |
| 画风 | 体素（Voxel），一格一方块 | 见 `docs/art-style.md` |
| 战斗节奏 | 技能驱动，普攻为辅助 | 偏 MOBA / 动作，不偏刷怪 |
| 风险结构 | 全掉落（保险格除外） | 塔科夫 |
| 成长结构 | 星图横向铺开 | Grim Dawn 星座 |
| 玩家关系 | 可 3 人组队，也可独狼 | — |

**和市面产品的差异点**：

- 市面搜打撤基本强制 PVP，我们**给纯 PVE 玩家一条完整路径**（主线 + 副本 + 领地）
- 市面搜打撤靠"搜容器"制造静态风险，我们**用可破坏物 + 站桩窗口**替代（见 10.5）

## 2. 模式结构

```
游戏
├─ 主线关卡（Story）      —— 有剧情，可重复体验，无道具产出，失败不掉装备
│    └─ 通关 → 占领领地 → 持续产出（时间 + 材料）
├─ PVE 副本（Dungeon）    —— 无剧情，纯 PVE，产道具，品质有硬上限
└─ PVPVE                 —— 带装备进场，高价值产出，玩家互相抢，无二次机会
```

**要点**：

- **没有纯 PVP 模式**。一切 PVP 都发生在有怪的地图里，PVE 元素是强制项（逼玩家交战、暴露信息）
- PVE 副本与 PVPVE **共用同一套地图** → 玩家在 PVE 里熟悉地图，等于在 PVPVE 里获得信息优势
- 主线关卡**一次性的道具奖励**只在首通发放，关卡内不产道具；但主线给**星图点**（见 6.3）与**永久解锁**（领地 / 副本 / NPC）

## 3. 核心循环

### 3.1 局外循环（长线）

```
推主线 → 占领领地 → 领地持续产出（材料 + 装备）
   ↑                        ↓
星图点数 ←──────────── 副本刷材料 / 装备
   ↓                        ↓
强化流派 ────────────→ 带更强配置下更高难度的图
```

### 3.2 局内循环（15 分钟）

见第 10 章。

### 3.3 三层经济

```
PVE 副本（出"量"，安全）
      ↓ 低阶材料
领地生产（消化材料 + 时间，出"中阶"）
      ↓
PVPVE（出"质"、独有收藏品、最高品质）
```

**设计意图**：PVE 的产出不是"次等品"，而是**领地的原料**。这样"鼠鼠玩家"的时间有去处，经济闭环不缺环。

## 4. 风险与死亡规则

| 场景 | 死亡 / 失败后果 |
|:--|:--|
| 主线关卡 | **身上 + 背包全不掉**（剧情优先，不惩罚） |
| PVE 副本 | 掉落在**死亡地点**。下一次进本可**捡回一次**；**第二次死亡 = 永久消失**（魂系捡魂 / 鸭科夫） |
| PVPVE | **无二次机会**，全部掉落，任何人可拾取 |

**细则**：

- 掉落范围：**已穿戴 10 个装备槽 + 背包全部**，**保险格除外**
- **保险格**是付费消耗品（占格要买），用来降低风险
- **裸装取回**是允许的，但路上有怪 —— 这是设计内的风险，不是漏洞
- **白色起步装**：进副本时若身上无装备，默认穿戴一套白装。规则：**不可带出、不可被他人拾取、不参与套装效果**（避免白装污染战利品池、避免白装凑套）

## 5. 经济系统

### 5.1 产出去向

| 物品类型 | 用途 |
|:--|:--|
| 武器 / 护甲 / 首饰 | 穿戴、被消耗（掉落 / 耐久） |
| **收藏品** | 纯换金道具，不占装备槽、占背包格、可堆叠。**极其稀有的收藏品是搜打撤的核心贪婪驱动之一**（见 7.5） |
| 低阶材料 | 领地生产原料 |
| 星图点（不可交易） | 成长，见 6.3 |

### 5.2 抗通胀：四条出口

因为我们**不做赛季重置**，通胀必须靠持续消耗压住：

| 出口 | 说明 |
|:--|:--|
| **耐久** | 近战武器按**造成 / 承受伤害**扣耐久；修理成本**随次数递增**（修不如重铸） |
| **消耗品** | 红药 / 蓝药 / 箭矢，全部是局内消耗 |
| **保险格** | 占格付费 |
| ~~洗点~~ | v1 曾是出口，**v2 改为免费**（见 6.4）→ 由下面一项替代 |
| **词条重铸** | 把"强化某技能"的词条重铸成别的技能；**废装变原料**，同时把"废装率"转成经济出口 |

### 5.3 装备消耗品化（核心原则）

> **不把"刷出顶级装备"做成玩家的终极目标。**

Dungeonborne 的教训：装备太稀有 → 玩家拿到就退游，且不敢带进战斗。所以我们：

- **不靠掉率控制稀有度**，靠**产出速率**调节供需
- 顶级装备应该"贵但常见"，是**可替换的筹码**，不是奖杯
- 套装门槛要低（见 7.3），否则凑不齐 = 不敢穿

## 6. 角色养成

### 6.1 养成四轴

| 轴 | 来源 | 给什么 | 会掉吗 | 洗点 |
|:--|:--|:--|:--|:--|
| 等级 | 击杀经验 | **星图点**（**不给基础属性**） | 不掉 | — |
| 技能 | 星图节点 | 无独立等级：**解锁即完整**，不做技能升级 / 形态变体 | 不掉 | 随星图 |
| **星图** | **等级 + 主线首通 + 主线探索事件** | 百分比乘区 + 解锁主动技能 + 被动 | 不掉 | **免费** |
| 装备 | 掉落 | 固定白值 + 词条 + 套装 + 附加效果 | **全掉** | 不可洗（只能重铸） |

> **没有"技能点"这种资源。** 全局只有一种成长货币：**星图点**。
> 技能不靠点满成长，它的强度来自星图乘区 + 装备白值。

### 6.2 分工红线

- **星图管横向**（玩法、机制、乘区）—— **主要强度来源**
- **装备管纵向**（白值 + 附加效果）—— **次要**
- **主动技能只来自星图**，装备**不增加**主动技能数量
- 被动技能来自星图 + 装备词条（"每 X 秒触发"或常驻）
- **装备不改变技能的核心定位**，只加"附加效果"（分裂、附加 DOT、免减速这类**锦上添花**），**不允许"拥有即质变"**

### 6.3 星图（对标 Grim Dawn 星座）

**借鉴的是设计思想，不是照搬**：

- ✅ 保留：**路径约束**（解锁高阶节点需要前置）—— 这是深度的来源，没有约束的星图 = 一堆自由选项 = 没有 build 感
- ✅ 保留：**有限点数 + 取舍**
- ❌ 不照搬：50 点规模、5 色亲和、Celestial Power 绑技能吃经验、魔法值般的复杂规则

**点数来源（三条，缺一不可）**：

| 来源 | 性质 |
|:--|:--|
| **等级提升** | 稳定、可预期的日常成长 |
| **主线首通** | 一次性、结构性 |
| **主线关卡内的探索事件**（修复神龛类、特殊任务、隐藏区域） | 一次性、鼓励探索 |

> **结构性约束（重要）**：等级有上限，所以**不推完主线就拿不满全部星图点**。
> 主线不是"加速器"，是"进度门槛"——玩家总归要把主线体验完，才能解锁完整星图。

**衍生推论（自然成立，不需额外设计）**：

```
主线进度 = 星图点数上限 = 战力天花板 = 匹配分层依据
```

（接住"低难度 PVPVE 地图限制星图点数"这条设计，本质是同一条链的末端。）

**数值**：点数总量**不固定**，按实测调整。v1 写的"30 点"只是示例，不作为约束。

### 6.4 流派 ≠ 角色

> **职业是 Build，不是角色。** 没有"创建角色时选法师"这回事。

- 一个角色，**星图怎么点就是什么流派**
- 换流派 = 重置星图，**完全免费、无消耗、无冷却**

**为什么免费**：

- 让玩家多体验几套 build 是好事，卡洗点会劝退
- "点一套更适合 PVE 的星图去刷副本"**没有任何问题** —— 这正是玩法自由

**代价（已知并接受）**：

- **build 没有身份感**：玩家不会觉得"我是火法玩家"，只会觉得"我在用火法"
- 可以随时按场合切最优解（打 boss 前洗单体、清怪洗 AOE）
- 取舍不来自系统，来自**装备在仓库里的储备**和**你愿不愿意重配**

## 7. 装备系统

### 7.1 词条分档

| 层 | 谁有 | 内容 |
|:--|:--|:--|
| **主 / 副词条** | 所有品质 | 纯数值，区间随机 |
| **套装词条** | 有套装的中高品质 | 锁血这类**强效**，**凑齐套装才生效** |
| **独立词条 = 技能附加词条** | **仅最高品质** | 分裂、附加 DOT、免减速等，**锁部位**（见 7.2） |

> 用户原话："技能附加词条和独立词条就是一回事。"不做质变，本质锦上添花。

### 7.2 附加词条锁部位（防止叠加）

**规则**：某个技能的全部附加效果，**只可能出现在同一个固定部位**上。

| 例子 | 锁定部位 |
|:--|:--|
| 火球的分裂 / 附加点燃 | **武器** |
| 位移技能的附加效果 | **鞋子** |

**为什么这样能防叠加**：同一部位只能穿一件 → 同类效果天然不会叠加，**不需要额外规则**。

**配套细则**：

- **双武器槽：只有激活槽的武器词条生效**（否则两把武器都带"强化火球"就破了约束）
- 一个技能的附加效果全锁一处 → **这个技能的成长天花板就是一件装备**（已接受：它是锦上添花，不承担成长）
- **废装率高是设计意图**：火法玩家爆到"强化冰箭"的武器，反而会被引导去试一套冰系 build（掉落引导 build 发现）。缓解手段是"词条重铸"（见 5.2）

### 7.3 套装（⚠ 件数待定）

| 方案 | 说明 |
|:--|:--|
| **2 / 3 件（推荐）** | 搜打撤里装备是消耗品，高门槛套装凑不齐 = 没人敢穿 |
| 2 / 4 / 6 件 | 只有"缺件降级而非消失"才可行 |

**已定**：只有高品质装备才有套装效果；白装不参与套装；**锁血这类强效只能做套装词条**（必须凑齐才生效）。

### 7.4 武器类型与消耗（抗通胀核心）

| 武器类型 | 普攻代价 | 耐久 | 说明 |
|:--|:--|:--|:--|
| 近战 | 免费（不耗蓝） | **消耗耐久（承受伤害为主）** | 贴身挨打多 → 掉得快 |
| 法术（法杖） | **消耗法力** | **消耗耐久（造成伤害为主，速率低）** | v3 起加耐久（v2 曾定为"不设耐久"） |
| 远程（弓/弩） | **消耗箭矢** | **消耗耐久（造成伤害为主，速率低）** | 同上 |

> **耐久损耗权重建议 承受 : 造成 ≈ 7 : 3。**
> 这样近战（贴身承受多）天然更费，远程（拉开承受少）天然更省 ——
> 给远程加耐久不会变成"额外惩罚"，只是堵住"远程完全免费"的口子。
>
> ⚠ **成本平衡不了强度。** 远程真正的强度平衡点在"**被贴脸就废**"（无法普攻 / 施法被打断 /
> 受额外伤害），不在"修装备贵"。钱只能决定谁玩得起，决定不了谁更强 —— 耐久是经济出口，不是平衡工具。

### 7.5 装备权重定位（重要原则）

> **装备不决定"赢不赢"，决定"赚多少"。**

| 装备该影响 | 装备不该影响 |
|:--|:--|
| 清怪速度、撤离成功率、抗性、容错、生存 | 技能机制、PVP 胜负手 |

**PVP 里的强度边界**：

- 装备好的一方**应该有一定比例的优势**（不是"完全平等"）
- 但这个优势**不能成为压倒性优势** —— 装备差的一方必须还能靠操作翻盘

**为什么这个定位健康**：

- PVP 胜负靠操作（设计意图）
- 装备强 → 刷得快、撤得多、赚得多 → 强者越来越富（搜打撤的正反馈）
- 富人不无敌，只是**效率高** → 不会出现"穿神装就赢"
- 和耐久天然咬合：**好装备打得快、也用得快** → 高收益伴随高成本

**"贪"的驱动由谁承担**：

- 装备只提供"效率"，提供不了"我捡到宝了"的兴奋 → 这份情绪交给**极其稀有的收藏品**（见 5.1）
- 收藏品不参与战斗，纯粹是价值符号，因此可以做得极稀有而不破坏平衡

### 7.6 预设构筑（v3 替代 v2 的"耐久分档"）

**问题**：装备是消耗品 + 有耐久，那"围绕一件神装建 build"就不成立（没法花两周）。

- **v2 的设想**：给稀有装备更高耐久 → 让装备活得久一点。
- **v3 的解法（用户提出）**：既然洗点免费，索性提供**预设加点方案**（预制构筑槽）——
  捡到冰系神装，一键切到冰系构筑即可，**重建一套 build 的成本接近 0**。

**这个解法更优**：

- 不需要给装备分耐久档（少一个需要平衡的数值轴）
- 玩家可以**并行维护多套构筑**（冰法 / 火法 / 近战），捡到什么玩什么
- 把"装备引导 build 发现"从"赌运气"变成**可执行**的玩法

**结构性后果（重要）**：

> **build 的约束从"点数"整体转移到了"仓库里有什么装备"。**

你没有冰系装备，就组不出冰系 build。于是：

- **装备的多样性与产出速率，比点数预算更决定玩法丰富度**
- 仓库容量、装备保留策略（哪些留着养 build）成为玩家要真正管理的资源
- 点数的角色从"限制"变成"表达"—— 它只决定这个 build 怎么长，不决定你能不能玩

**风险**：切换零成本 → 玩家会收敛到"当前最强 build"。
天然的反制是**装备库存**（你不一定凑得出那套）+ **附加词条锁部位**（不同 build 抢不同部位）。见 R12。

## 8. 战斗系统

### 8.1 基本规则

| 规则 | 决定 |
|:--|:--|
| 暴击 | **不做** |
| 破防 / 处决 | **不做** |
| 部位判定 | **不做**（只做命中判定，2.5D 不做 FPS 的精细命中） |
| 主要输出来源 | **技能**（普攻为资源 / 收尾 / 过渡） |
| 胜负来源 | 技能释放、连招、躲避、招架、地形、套装特效 |
| 基础攻速 | 偏低（降低普攻在战斗中的比重） |
| 普攻后摇 | **可被技能 / 闪避取消**（取消本身就是技巧点） |

### 8.2 技能栏

| 项 | 规则 |
|:--|:--|
| 主动技能栏 | **7 格** |
| 位移技能 | **算主动技能，占 1 格** |
| 空格闪避 | **角色自带，独立于技能栏**（不占格） |
| 实际能带几个 | 点数预算天然把主动技能压到 **4–5 个**（因为被动也吃点数），7 格是宽松上限 |
| 技能解锁成本 | **便宜**（推荐 1 点）—— 否则玩家不敢解锁"用不上"的技能，技能库永远只有 4 个，丰富感消失 |

> **取舍发生在星图，不发生在战前**：解锁什么就带什么，没有"进图前选 4 个"的环节。
> 好处：规则简单；代价：点错技能只能洗点（免费，所以代价很低）。

### 8.3 资源与消耗品

| 资源 | 规则 |
|:--|:--|
| 生命 | 常规 |
| 法力 | **不自动恢复**。技能释放消耗（所有流派都耗，依赖度不同）。恢复靠**蓝药**（缓慢回复） |
| 弹药 / 耐久 | 见 7.4 |

> **没有"流派专属资源"**（曾经设计过战士怒气，已废弃）。
> 原因：星图是所有人共用的，专属资源放前面则人人都有，放后面则前期没有，都不成立。

### 8.4 状态效果表

**硬控**（禁止操作类）

| 状态 | 效果 | 反制 |
|:--|:--|:--|
| 晕眩 | 禁止操作 | 无解，但时长短（≤1.5s） |
| 石化 | 禁止操作 | 连点闪避缩短时长；被击碎时受额外伤害 |
| 睡眠 | 禁止操作 | 受击即醒；睡眠中首次受伤 +50% |
| 禁锢 | 禁止移动 / 位移技能 / 闪避 | **可以原地攻击、放非位移技能**（不额外给反制） |

**软控 / 削弱**

| 状态 | 效果 |
|:--|:--|
| 减速 | 移动速度降低（追逃的基础） |
| 迟滞 | 攻速 / 施法速度降低 |
| 沉默 | 禁止释放技能 |
| **缴械** | 禁止普通攻击（对法系/刺客影响天然较小，符合设计意图） |
| 目盲 | 大幅降低视野 |
| 标记 | 位置在对方小地图显示一段时间 |
| 足迹 | 留下可追踪痕迹 |
| 重伤 | 治疗效果降低（比"点燃=完全禁疗"温和的一档） |
| 破甲 | 护甲降低 |
| 易伤 | 受到伤害增加 |
| 燃蓝 | 按损失法力造成伤害 |
| CD 延长 | 技能冷却变长 |

**持续伤害**

| 状态 | 效果 |
|:--|:--|
| 流血 | 持续伤害 |
| 中毒 | 可叠层，持续伤害 |
| 点燃 | 持续伤害，**效果结束前治疗无效** |

**位移类**

| 状态 | 效果 |
|:--|:--|
| 击退 / 击飞 | 位移；撞墙 = 额外伤害 + 短暂眩晕 |
| 拉拽 | 把目标拉向自己 |
| 打断 | 打断引导类技能 |

**规则**：

- **不做状态累积条**，命中即上状态（PvP 里展示进度条太乱）
- **不做状态递减（DR）** —— 玩家已决定，理由：硬控本身是"难命中 + 长 CD + 非指向性"，且递减有理解成本。**风险见第 14 章 R1**
- **硬控均为非指向性技能，CD 较长**；越难命中，命中奖励越大
- **引导类技能必须有极显眼的引导动作**（读条提示），让对手能反应、能打断

### 8.5 反应链

只做 3 类、固定条目，**不做"状态两两组合"**（避免 N² 学习成本）。

**元素反应**

| 组合 | 效果 |
|:--|:--|
| 水 + 冰 | 冻结（硬控） |
| 水 + 雷 | 麻痹，向附近敌人**传导** |
| 火 + 毒 | **引爆**毒层，瞬间伤害 |
| 油 + 火 | 地面火海（油 = 减速 + 易燃） |
| 风 + 火 / 风 + 毒 | 火势 / 毒雾**扩散** |

**物理反应**

| 组合 | 效果 |
|:--|:--|
| 击退 / 拉拽 + 墙 | 撞墙：伤害 + 短暂眩晕 |
| 击退 + 陷阱 / 毒池 / 边缘 | 地形杀 |
| 流血 + 位移 | 地面血痕，可被追踪 |
| 石化 + 击碎 | 碎裂：高额伤害，终结石化 |

**技能链**

| 组合 | 效果 |
|:--|:--|
| 控制命中 → 高伤害技能 | 必中 / 极高命中 |
| 位移技能 → 已铺好的地面效果 | 把目标送进火海 / 毒池 |

> **连招原则：每一环都必须单独有收益。** 不允许"B 技能只为 A 技能服务"——B 空了 A 也空了时，B 本身要有位置/资源/减速等价值，否则玩家不敢用。

### 8.6 招架（Parry）

**不做帧级弹反，做"招架式"**（Fiora W 类），因为俯视角 + 多目标 + 输入延迟不适合帧级判定。

| 项 | 规则 |
|:--|:--|
| 架势 | 按下进入 **0.4–0.6 秒**招架架势 |
| 生效 | 姿态内受到**正面**攻击 → 完全免伤 + 反击 |
| 方向 | **只挡正面**，侧面与背后照常受伤 |
| 失败 | **不可取消的僵直**（惩罚足够重，配得上收益） |
| 表现 | **强 hitstop + 白闪 + 金属音效**（手感 80% 来自这三样） |

### 8.7 地形（2.5D 独有优势）

| 用法 | 说明 |
|:--|:--|
| 高度差 | 高台可打下面，下面打不到上面 |
| 可推落边缘 | 击退 → 摔伤 + 脱离 |
| 撞墙 | wall bounce（伤害 + 短暂眩晕） |
| 可破坏墙 | 打穿创造新路线（与可破坏物共用系统） |

## 10. 单局结构（15 分钟）

### 10.1 时间预算

| 项 | 时长 |
|:--|:--|
| 单局总长 | **900 秒** |
| 战斗 | 约 500 秒 |
| 移动 / 赶路 | 约 160 秒 |
| 决策 / 搜刮 / 破坏物 | 约 100 秒 |
| 撤离追逐 | 约 140 秒 |

### 10.2 三段式节奏

| 时间 | 阶段 | 玩家在做 | 系统在推 |
|:--|:--|:--|:--|
| 0:00–4:00 | **探索** | 定路线、看地形、打第一波 | 低密度怪、出生点分散、无强制战斗 |
| 4:00–11:00 | **交战** | 抢事件、打精英、打可破坏物 | **7–8 分钟高价值事件刷新**（声音 + 光效提示） |
| 11:00–15:00 | **撤离** | 往传送门跑，可能被追 | 传送门开启、怪向传送门聚集 |

> **7–8 分钟的事件刷新是每局的情绪高点**：逼玩家做"抢或收手"的决定。

### 10.3 战斗节点

一局 900 秒只够 **4–5 个节点**（每个含接近、拉怪、清场、破坏、拾取，100–140 秒）。

> **一局只能让玩家记住 3 件事** —— 节点必须有"记忆点"，不能是均匀的怪群。

**节点 = 三个选择**：

| 维度 | 选项 |
|:--|:--|
| 入口 | 正面打（快、伤）/ 绕后（慢、安全）/ 打穿可破坏墙（花时间，造新路线） |
| 层次 | 小怪（资源）、精英（威胁）、可破坏物（收益）空间交错，玩家自选顺序 |
| 出口 | 清干净（时间成本）/ 拿完就走（留怪在背后）/ 主动拉怪到别处（战术撤退） |

### 10.4 怪物角色（组合 > 单体）

| 角色 | 作用 | 设计要点 |
|:--|:--|:--|
| 填线 | 资源与节奏 | 多、脆，2–3 刀死，负责"爽" |
| 压制（远程） | 破坏站位 | 逼玩家移动、打断打可破坏物 |
| 威胁（精英） | 必须用技能应对 | 高伤 + 明显起手，可被招架 |
| 控制 | 限制行动 | 逼玩家优先处理 |
| 支援 | 给其他怪加 buff | 优先级最高，逼玩家改击杀顺序 |
| 词条（affix） | 随机性 | 火链、冰霜、吸血、狂暴 |

> **组合决定 build 是否有效**：全填线 → AOE 通吃；混支援 + 远程 → 必须点单点爆发。配装才有意义。

### 10.5 可破坏物（替代"搜容器"）

市面搜打撤的"搜"靠 UI 遮挡制造脆弱时刻（蹲下、视野被挡、不能动），我们**用动作语言替代**：

| 设计 | 说明 |
|:--|:--|
| 高价值可破坏物需要**持续攻击 2–4 秒** | 期间**站桩、不能移动、动作锁死、有挥砍音效** |
| 更高级的需要**特殊动画（更长时间）** | 窗口更长、更响、更值得埋伏 |
| **破坏会惊醒周围的怪** | 玩家必须**先清场再破坏** —— 把静态风险变成动态风险 |
| **最高价值物需要"机关"** | 先点燃 / 击碎护罩 / 打掉守卫，窗口最长 |

> 三个要素（背身、站桩、声音）全齐，偷袭玩法成立，且比"蹲着看进度条"更符合 2.5D 的动作感。

### 10.6 撤离：传送门

**不使用"撤离点"，包装成传送门。** 必须有"撤"的过程。

**状态机**

```
关闭 ──(拉闸 / 时间事件)──→ 已激活 ──(玩家引导 8–12s)──→ 开启 ──(1 人撤离)──→ 已激活
                               ↑                                              │
                               └──────────── 次数耗尽 ──→ 关闭 ←──────────────┘
```

**规则**

| 项 | 规则 |
|:--|:--|
| 开启方式 | 玩家**引导 8–12 秒**（可视为引导技能），分 3 段进度（每段有音效/光效） |
| 打断 | **打断清空进度** + 3 秒硬直（否则骚扰无意义） |
| 撤离 | 开启后撤离是**瞬间**的 |
| 开启次数 | 每扇门有固定次数（例：3 次），**每次只允许 1 人撤离**，用完后进入关闭 |
| 关闭后 | 永久关闭（次数耗尽） |
| 数量关系 | **门数量 > 同时在场玩家数**（例：5 扇门 / 3 人），制造抢门压力但不制造"必死" |
| 广播事件 | 可做"拉闸"：拉闸后 1 分钟，某处传送门开启 + **全图广播**（把开门变成公开事件，制造埋伏窗口） |

**为什么不需要"开门者优先通行权"**：开门者天然离门最近，且撤离是瞬间的 —— 他不会被自己开的门坑到（除非被控住，那是玩法，不是漏洞）。

> **组队时**：一人开门、三人走的问题后议（可能做群体传送门）。当前只做单人。

## 12. 数值与经济公式

### 12.1 产出必须 ≥ 损耗 × 1.2

```
单局期望损耗 = 死亡率 × 带入装备价值
单局期望产出 = 出货价值 × 撤离率
要求：单局期望产出 ≥ 单局期望损耗 × 1.2
```

例：带入 1000、死亡率 30% → 每局损耗 300 → **每局平均要打出 360 的货**。

> 产出不够 → 玩家越玩越穷，这是**节奏问题**（局太短 / 死得太频），不是单纯数值问题。
> Dungeonborne 后期的"装备断层"通常就失衡在这里。

### 12.2 时间锚点

- 一局 900 秒 → **每小时约 4 局**
- 死亡率 30% → 每小时死 1.2 次 → 需每小时产出 1.2 套可用装备
- 所有掉落表按这个速率配（用户已授权由我配表）

## 15. 与现有工程的差距

当前工程（见 `HANDOFF.md`）是「出击 → 通关/阵亡 → 整份搬回/丢弃」的单局结构，与本文档的差距：

| 本文档要求 | 现状 | 工作量 |
|:--|:--|:--|
| 关卡分类（主线/副本/PVPVE） | `deploy` 只发 `seed + loadout` | **小**：加 `kind` 字段即可分流规则 |
| 收藏品（换金道具） | 只有武器 / 护甲 / 首饰 | **中**：新物品类 + 堆叠 + 新表 |
| 技能系统（7 格 + CD + 施法） | **只有普攻** | **大** |
| Debuff / 反应链 | 无 | **大**：统一状态注册表 + 结算顺序（别散落在 `paint.ts`） |
| 星图 | 有天赋选点（3 条断言） | **大**：重做为"等级/主线给点 + 路径约束 + 免费洗点" |
| 等级 / 经验 | 无 | **中** |
| 耐久 / 消耗品 | 无 | **中** |
| 15 分钟节奏 / 传送门 | 无撤离概念（通关即结束） | **大**：撤离、门状态机、单局计时 |
| 大地图 / 分区 / 大地图 UI | 单张 128×96 | **大** |
| 可破坏物 | 无 | **中**（新系统 + 美术） |
| 组队 / 联机 | 无 | **很大**，最后做 |

> **建议实现顺序**：先补"单局骨架"（撤离 + 15 分钟 + 节点）→ 再补"战斗深度"（技能 + 状态 + 反应）→ 再补"养成"（星图重做 + 等级 + 耐久）→ 最后做组队。
> 理由：单局骨架决定所有参数，做反了要重来。
