## 6. 角色养成

### 6.1 养成四轴

| 轴 | 来源 | 给什么 | 会掉吗 | 洗点 |
|:--|:--|:--|:--|:--|
| 等级 | 击杀经验 | **星图点**（**不给基础属性**） | 不掉 | — |
| 技能 | 星图节点 | 无独立等级：**解锁即完整**，不做技能升级 / 形态变体 | 不掉 | 随星图 |
| **星图** | **等级 + 主线首通 + 主线探索事件** | 百分比乘区 + 解锁主动技能 + 被动 | 不掉 | **免费** |
| 装备 | 掉落 | 固定白值 + 词条 + 套装 + 附加效果 | **全掉** | 不可洗（只能重铸） |

> **没有"技能点"这种资源。** 全局只有一种成长货币：**星图点**。
> 技能不靠点满成长，它的强度来自星图乘区 + 装备白值。

### 6.2 分工红线

- **星图管横向**（玩法、机制、乘区）—— **主要强度来源**
- **装备管纵向**（白值 + 附加效果）—— **次要**
- **主动技能只来自星图**，装备**不增加**主动技能数量
- 被动技能来自星图 + 装备词条（"每 X 秒触发"或常驻）
- **装备不改变技能的核心定位**，只加"附加效果"（分裂、附加 DOT、免减速这类**锦上添花**），**不允许"拥有即质变"**

### 6.3 星图（对标 Grim Dawn 星座，v7 重做）

> **v7 推翻 v6 的读法**：~~路径约束 = 节点前置连线~~。用户 2026-11-15 指出：星图的核心是
> **亲和点数**，不是连线；被动也不该是"为某个主动技能加成"。已按此重做（见 15.0）。

**核心机制：亲和（affinity）**

| 项 | 规则 |
|:--|:--|
| 亲和是什么 | **只累积、不消耗**的颜色点数。六种颜色＝六种元素（火 / 冰 / 水 / 毒 / 雷 / 风） |
| 从哪来 | **每个节点都产出亲和**：技能节点给本色 2 点 + 邻色 1 点；被动节点给本色 1 点 + 邻色 1 点 |
| 有什么用 | **星座的开锁门槛**。星座只认自己颜色的亲和，例如「怒雷」需要 3 点雷亲和 |
| 没有的东西 | ❌ 节点之间的前置 / 连线 ❌ 亲和消费 ❌ 5 色之上的额外规则 |

**为什么这样更耐玩**：想开高阶星座，就得先去别的星座攒颜色 —— 而攒颜色的那些点，往往不是
你真正想要的。**取舍来自"绕路"，不是来自"点不亮"**。这是 Grim Dawn 星座真正的深度来源。

**节点分三类**（被动一律通用，**不为某个技能服务**）：

| 类型 | 给什么 | 例子 |
|:--|:--|:--|
| 主动技能 | 解锁一个技能（不带等级，解锁即完整） | 火墙 / 冰锥 / 冲锋 |
| 属性 | 通用乘区：伤害 % / 生命 % / 法力 % / 近战距离 | 「燎原」所有伤害 +5% |
| 大点（passive） | 同类乘区的更大号，单个 2 点 | 「破军」所有伤害 +12% |

> **红线**：属性与大点**不得**写成"提升某个技能"（例如"横扫伤害 +20%"）。技能的强度只来自
> 通用乘区 + 装备白值（6.2）；一旦绑定具体技能，星图就会退化成"点满自己那个技能的技能树"。

**点数来源（三条，缺一不可）**：

| 来源 | 性质 |
|:--|:--|
| **等级提升** | 稳定、可预期的日常成长 |
| **主线首通** | 一次性、结构性 |
| **主线关卡内的探索事件**（修复神龛类、特殊任务、隐藏区域） | 一次性、鼓励探索 |

> **结构性约束（重要）**：等级有上限，所以**不推完主线就拿不满全部星图点**。
> 主线不是"加速器"，是"进度门槛"——玩家总归要把主线体验完，才能解锁完整星图。

**衍生推论（自然成立，不需额外设计）**：

```
主线进度 = 星图点数上限 = 战力天花板 = 匹配分层依据
```

（接住"低难度 PVPVE 地图限制星图点数"这条设计，本质是同一条链的末端。）

**数值**：点数总量**不固定**，按实测调整。v1 写的"30 点"只是示例，不作为约束。

#### 6.3.1 点数配比（v7 暂定，开发期可调）

| 用途 | 例（当前落地的 8 星座 / 24 节点） | 说明 |
|:--|:--|:--|
| **主动技能** | 7 个 × 1 点 | 解锁便宜；技能同时还产亲和，是"顺手推色"的主要手段 |
| **属性 / 乘区** | 12 个 × 1 点 | 通用乘区，1 点/个 |
| **大点** | 4 个 × 2 点 | 高门槛星座里的甜点 |
| **起点星座** | 2 个（火 / 冰）不需亲和 | 保证第一点永远点得下去 |

**当前规模**：满级 18 点 + 主线首通 2 点 + 探索事件若干 = 约 20 点，而点满全部节点需要 **26 点**
—— 拿不全，必须取舍。

**为什么技能也产亲和**：Grim Dawn 里"顺手点的星座"同时给属性和亲和，所以过渡不亏。
如果技能只解锁技能、不产色，玩家会被迫为了开星座去点纯属性点，那是"点数被地形吃掉"的挫败。

### 6.4 流派 ≠ 角色

> **职业是 Build，不是角色。** 没有"创建角色时选法师"这回事。

- 一个角色，**星图怎么点就是什么流派**
- 换流派 = 重置星图，**完全免费、无消耗、无冷却**

**为什么免费**：

- 让玩家多体验几套 build 是好事，卡洗点会劝退
- "点一套更适合 PVE 的星图去刷副本"**没有任何问题** —— 这正是玩法自由

**洗点的位置限制（v4）**：

> **洗点只能在战局外（大厅 / 局外界面）进行，局内不能操作星图。**

- 局内**不能换 build**：带进去的是什么，这一局就是什么，打完才能改
- 所以"打 boss 前洗单体、清怪洗 AOE"只能发生在**进图之前**，不是本局中途

**代价（已知并接受）**：

- **build 没有身份感**：玩家不会觉得"我是火法玩家"，只会觉得"我在用火法"
- 取舍不来自系统，来自**仓库里有什么装备** + **这一局带哪套预设方案**
- 真正的取舍时刻被推到"赛前"，而不是"战中" —— 这也正好和搜打撤的"配装下局"节奏一致
