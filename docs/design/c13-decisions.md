---


所以搜打撤的"埋伏"要靠三件事撑起来，缺一个就不成立：

1. **控制**（硬控/减速）—— 让你追得上
2. **位移差**（拉拽/击退/封路）—— 让对手跑不掉
3. **信息**（标记/足迹/视野遮挡）—— 让你找得到

**PVP 伤害系数**（Q5）：数值本身灵活调，只要满足上表即可；不要为了"爽"把 PVP 拉到 2 秒。

## 13. 决策总表

### 13.1 已定

| # | 项 | 决定 |
|:--|:--|:--|
| 1 | 模式 | 主线 + PVE 副本 + PVPVE，**无纯 PVP** |
| 2 | PVE 副本产出 | 品质**硬上限** + 爆率调整；PVPVE 独占最高品质与高级收藏品 |
| 3 | 死亡规则 | 主线不掉；副本掉原地可捡回一次、二次永久消失；PVPVE 无二次机会 |
| 4 | 保险格 | **独立容器**（不占背包格），付费扩容；保险格内不掉；**初始赠送 2 格** |
| 5 | 白装 | 入场无装备时默认穿戴；不可带出 / 不可被拾取 / 不参与套装 |
| 6 | 领地 | 通关主线解锁；消化**低阶材料 + 时间**持续产出 |
| 7 | 主线 | 给星图点与永久解锁；关卡内不产道具；首通一次性奖励 |
| 8 | **星图点来源** | **等级提升 + 主线首通 + 主线探索事件**；不推完主线点不满 |
| 9 | 星图数值 | **不固定**（v1 的"30 点"只是示例），按实测调 |
| 10 | 成长货币 | **全局只有星图点一种**，没有技能点 |
| 11 | 技能 | 解锁即完整，**无技能等级 / 形态变体** |
| 12 | 技能栏 | **主动 7 格，含位移**；空格闪避独立不占格；点数自然压到 4–5 个 |
| 13 | 流派 | **由星图决定，不是角色**；洗点**完全免费** |
| 14 | 技能来源 | 主动 = 星图；被动 = 星图 + 装备；装备**不增加**主动技能数量 |
| 15 | 装备对技能 | **只加附加效果（锦上添花），不改核心、不质变** |
| 16 | 装备定位 | **消耗品，非奖杯**；**提高胜率**（贵 = 死亡代价大 = 理应更强），但**必须留可执行的翻盘路径**，不允许"操作再好也必败" |
| 17 | 词条分档 | 主/副词条（全品质）→ 套装词条（中高品质）→ **独立词条 = 技能附加词条（仅最高品质）** |
| 18 | 附加词条 | **锁部位**（火球→武器，位移→鞋）；双武器槽**只有激活槽生效** |
| 19 | 废装 | 废装率高是**设计意图**（引导换 build），用**词条重铸**缓解 |
| 20 | 抗通胀 | 耐久（按伤害扣 + 修理递增）+ 消耗品 + 保险格 + **词条重铸** |
| 21 | 武器消耗 | **三类武器都有耐久**。近战→耐久（承受为主）；法术→法力 **+** 耐久（造成为主，速率低）；远程→箭矢 **+** 耐久（同上） |
| 22 | 资源 | **只有生命 + 法力**；法力**不自动恢复**，靠蓝药；**无流派专属资源** |
| 23 | 战斗基本盘 | 无暴击 / 无破防处决 / 无部位判定；技能为主，普攻为辅 |
| 24 | 普攻定位 | 资源 / 收尾 / 过渡；**后摇可被技能或闪避取消** |
| 25 | 硬控 | 非指向性 + 难命中 + 长 CD；**不做状态递减** |
| 26 | 状态 | 命中即上状态，**不做累积条** |
| 27 | 反应链 | 3 类固定条目（元素 / 物理 / 技能链），不做两两组合 |
| 28 | 招架 | 招架式（0.4–0.6s 正面窗口，失败有不可取消僵直） |
| 29 | 单局 | **15 分钟**，三段式（探索 / 交战 / 撤离） |
| 30 | 节点 | 4–5 个，每个 100–140 秒，有"记忆点" |
| 31 | 怪物 | 6 类角色（填线/压制/威胁/控制/支援/词条） |
| 32 | 搜 | 用**可破坏物 + 站桩窗口**替代搜容器 |
| 33 | 撤离 | **传送门**，8–12s 引导，分 3 段，可打断（**只清进度，无硬直**），有开启次数 |
| 34 | 地图 | 大幅扩张 + 分区域 + **环形** + 大地图查看 |
| 35 | 新手关 | 小地图、分钟级、剧情为主、可无技能；但必须闭环到第一个技能 |
| 36 | 组队 | **第 1 版不做**；只留扩展余地（见 2.1） |
| 37 | **预设构筑** | 提供**预设加点方案**（洗点免费，一键切换）；**build 的约束来自装备库存，不来自点数** |
| 38 | 洗点位置 | **只能在局外（大厅）进行，局内不能操作星图** |
| 39 | 套装件数 | **2–4 件区间都合理**，不锁死统一数字；不做 6 件套 |
| 40 | 元素体系 | **水 / 火 / 毒 / 雷 / 冰 / 风（6 种）**，5 条固定反应 |
| 41 | TTK | **PVP 10–20 秒**（极限 5 秒，须留还手空间）；**PVE boss ≥ 60 秒** |
| 42 | 点数配比 | 主动 ~10% / 被动 ~25% / 属性 ~45% / 路径 ~20%（见 6.3.1，开发期可调） |
| 43 | **账号体系** | **自建**（用户名 + 口令，存自有 CVM）；不用平台身份。**服务端只存用户名与口令哈希**，不收手机号 / 邮箱 / 身份证，不存设备指纹 / IP / UA |
| 44 | **游客** | **纯本地存档，一行都不进服务器**（避免孤儿数据）；注册时把本地存档迁上云。代价：清缓存 / 换设备即丢 |
| 45 | **输出来源** | **技能轴与普攻轴并立**，谁更强由 build 决定（2026-11-24 修订，原"主要靠技能、普攻为过渡"作废）。见 8.1 |
| 46 | **攻速** | 基础偏低；**只从技能与星图来，装备不给攻速**；上限按 TTK 锚点反推。见 8.1.1 |
| 47 | **终极技能** | `kind='ult'` 星图节点**全局只能点 1 个**（`canPick` 拒绝）；**不做**专属终极格。见 `design/skills-batch-1.md` |
